# Инструкция по настройке Telegram Mini App

## Шаг 1: Создание бота в BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: `Tonimi Casino`)
   - Введите username бота (должен заканчиваться на `bot`, например: `tonimi_casino_bot`)
4. Сохраните токен бота (он понадобится позже)

## Шаг 2: Настройка Web App

1. В BotFather отправьте команду `/newapp`
2. Выберите вашего бота из списка
3. Заполните информацию:
   - **Title**: `Tonimi`
   - **Short name**: `tonimi` (только латиница, без пробелов)
   - **Description**: `Играйте в Mines, Dice, Plinko и выигрывайте TON`
   - **Photo**: Загрузите иконку (512x512px, квадратная)
   - **Web App URL**: `https://tonimi.fun`
   - **GIF**: (опционально) Загрузите GIF анимацию
   - **Short name**: Подтвердите короткое имя

## Шаг 3: Проверка настройки

1. Найдите вашего бота в Telegram
2. Откройте бота
3. Нажмите на кнопку меню (три полоски) или кнопку "Menu"
4. Должна появиться кнопка с вашим Mini App
5. Нажмите на неё - откроется ваше приложение

## Шаг 4: Настройка кнопки в меню (опционально)

Если хотите добавить кнопку в меню бота:

1. В BotFather отправьте `/mybots`
2. Выберите вашего бота
3. Выберите "Bot Settings" → "Menu Button"
4. Выберите "Configure" → "Web App"
5. Введите URL: `https://tonimi.fun`

## Шаг 5: Проверка работы

1. Откройте бота в Telegram
2. Нажмите на кнопку Mini App
3. Приложение должно открыться в полноэкранном режиме
4. Проверьте подключение кошелька через TON Connect

## Важные замечания

- ✅ Сайт должен быть доступен по HTTPS
- ✅ Домен должен быть валидным (tonimi.fun)
- ✅ Манифест TON Connect должен быть доступен: `https://tonimi.fun/tonconnect-manifest.json`
- ✅ Backend должен работать на порту 3001
- ✅ Nginx должен быть правильно настроен

## Troubleshooting

### Mini App не открывается
- Проверьте, что сайт доступен по HTTPS
- Проверьте, что URL в BotFather правильный: `https://tonimi.fun`
- Убедитесь, что нет редиректов

### Ошибка подключения кошелька
- Проверьте манифест: `https://tonimi.fun/tonconnect-manifest.json`
- Убедитесь, что манифест возвращает правильный JSON
- Проверьте Content-Type заголовки

### Бот не отвечает
- Проверьте токен бота
- Убедитесь, что бот запущен (если используете webhook)

## Дополнительные настройки

### Настройка команд бота

В BotFather отправьте `/setcommands` и добавьте:
```
start - Начать игру
help - Помощь
balance - Проверить баланс
```

### Настройка описания бота

В BotFather отправьте `/setdescription` и добавьте описание вашего бота.

### Настройка About text

В BotFather отправьте `/setabouttext` и добавьте информацию о боте.
